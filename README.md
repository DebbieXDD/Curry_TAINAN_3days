## 🗓️ 三天兩夜詳細順路行程表

### 🛵 Day 1：11/21（六）國華街甜點巡禮 ➔ 神農街 ➔ 武聖夜市 ➔ 碳饅堡
> **路線動線**：台南車站租機車 ➔ 中西區（國華街／西市場／水仙宮商圈，5 間店步行 1～5 分鐘內！）➔ 武聖夜市 ➔ 金華路宵夜

* **11:30｜抵達台南火車站租機車、寄放行李**
  * 前站／後站租完機車後，先至旅店辦理登記並寄放行李。
* **12:30 – 15:30｜【國華街・西市場下午茶散步圈】**（停好機車，步行一次蒐集 3 家）
  * 🥖 **百珍西點麵包廠**（中西區西門路二段151號，西市場內）
    * **必吃推薦**：招牌「巨無霸泡芙」、古早味檸檬蛋糕、傳統克林姆麵包。
  * 🍩 **亞米甜甜圈專賣店**（中西區國華街三段6號）
    * **必吃推薦**：脆皮鮮奶甜甜圈、Q 彈小米甜甜圈（熱門口味售完為止）。
  * 🍦 **AIC Gelato 冰淇淋**（中西區國華街三段26號A7，淺草新天地內）
    * **必吃推薦**：每日手作義式冰淇淋，逛街熱了剛好一人一球消暑。
  * ✨ *順路加碼景點*：**正興街 ＆ 蝸牛巷**（民生路一段157巷），老宅文青選物店與巷弄裝置藝術超好拍。
* **16:00 – 17:30｜水仙宮百年美食 ＆ 神農街傍晚點燈**
  * 🍙 **水仙宮粽葉米糕**（中西區民權路三段44號）
    * **必吃推薦**：粽葉米糕＋四神湯；與「黃家鱔魚意麵」共用座位，兩個人可點小份分食，留肚子給夜市！
  * ✨ *順路加碼景點*：**神農街**（就在水仙宮對面步行 2 分鐘），約 17:00 燈籠亮起時最有復古情調。
* **18:30 – 21:30｜【必要景點】武聖夜市**（中西區武聖路69巷，週三、五、六營業）
  * **必吃推薦**：阿美嬤紅茶奶、三輪車大腸香腸、陳家阿嬤拔絲地瓜、蚵男鮮蚵、法式可麗餅；吃完還可玩夜市射氣球、打彈珠。
* **22:00｜碳饅堡（豆漿宵夜早點）**（中西區金華路三段89號，**週日公休**）
  * **必吃推薦**：炭火現烤「冰火碳烤饅頭（夾厚片冰奶油）」或「起司燒肉蛋饅頭」，兩人分食一顆當完美宵夜收尾。

### 🛵 Day 2：11/22（日）溫體牛肉湯 ➔ 小鹿家可頌 ➔ KTV 歡唱 ➔ 裁縫師深夜微醺
> **路線動線**：南區早餐 ➔ 中西區藝文拍照 ➔ 安南區買可頌 ➔ 台南 KTV 下午場 ➔ 河樂廣場 ➔ 裁縫師會館

* **08:00 – 09:00｜體育場樺哥土產牛肉湯**（南區體育路89號，**週一、二公休**）
  * **必吃推薦**：「上等花紋牛肉湯」＋銷魂肉燥飯（花紋肉限量，建議 08:30 前抵達；吃完若想補眠可先回旅店小憩）。
* **10:30 – 12:15｜✨ 順路加碼景點：台南市美術館二館 或 藍晒圖文創園區**
  * 早上光線好，推薦去**南美館二館**（純白幾何建築超好拍、室內有冷氣）或**藍晒圖文創園區**逛特色小店。
* **12:45 – 13:30｜小鹿家麵包店**（安南區海東七街49號，13:00 開門）
  * **必吃推薦**：招牌千層可頌、季節限定水果可頌、丹麥系列。門口滿滿綠植超好拍，建議 **12:45–13:00 開門前抵達**以免秒殺。
* **14:00 – 18:00｜【必要景點】台南在地 KTV 歡唱（避開正午大太陽＋下午場划算）**
  * 🎤 **首選推薦：賓士 KTV 中成店**（中西區中成路18號）或 **府前店**（中西區府前路二段）
  * **另一推薦：享溫馨 KTV 中華店**（東區中華東路）
  * **亮點**：台南 KTV 的熱炒、炸物、火鍋超乎想像地好吃，可直接在包廂邊唱邊吃午餐／下午茶，而且**現場結帳可刷信用卡**！
* **18:15 – 19:30｜✨ 順路加碼景點：河樂廣場 (The Spring) ＆ 海安路藝術街**
  * 唱完歌出來吹晚風，在親水廣場看夕陽與夜間燈光倒影。
* **20:00 – 22:30｜裁縫師會館**（20:00–02:00，週三公休）
  * **據點一（中西區首選）**：**裁縫師咖啡｜森參會館 bar**（中西區成功路359號3樓）— 露營風天台、深夜無菜單虹吸咖啡與特調。
  * **據點二（安平創始店）**：**裁縫師深夜咖啡館**（安平區延平街122號）— 安平老宅復古風、虹吸咖啡、調酒與港式蒸籠點心。
  * *(貼心提醒：騎車的朋友可點招牌無酒精特調或虹吸精品咖啡，後座朋友可微醺小酌！)*

### 🛵 Day 3：11/23（一）伴手禮採買 ➔ 東區銅板美食與嫩仙草 ➔ 傍晚搭高鐵賦歸
> **路線動線**：退房寄放行李 ➔ 邱惠美伴手禮 ➔ 東區美食線（蔥油餅＋88嫩仙草）➔ 台南車站還機車 ➔ 台鐵沙崙線至台南高鐵站

* **10:30 – 12:30｜退房寄放行李 ＆ 吳園藝文中心／早午餐散步**
  * 睡飽退房後將行李寄放在旅店或火車站，可順遊附近的 **吳園藝文中心**（日式木造屋＋古典庭園，清幽好拍）。
* **13:00 – 13:30｜邱惠美鳳梨酥（阿美鳳梨酥）**
  * **位置**：東菜市總店（中西區民權路一段88號）或 水仙宮店（民權路三段50號）。
  * **必買推薦**：古早味鳳梨酥、現烤手工古早味蛋糕（髒髒糕、布丁蛋糕、南瓜乳酪蛋糕）。排在最後一天買不用提三天！
* **14:00 – 15:00｜府東街147號蔥油餅**（東區府東街147號，**週日公休**）
  * **必吃推薦**：現炸加蛋蔥油餅、超人氣銅板價「芋頭餅、甜甜圈、雙胞胎」。
* **15:15 – 16:30｜88嫩仙草 光明店**（東區光明街147-4號）
  * **必吃推薦**：招牌手工嫩仙草（附奶油球）＋手炒黑糖芋圓。坐在店內涼涼地吃甜點聊天，從這裡騎回台南火車站只要 **5 分鐘**！
* **16:45｜回到台南火車站還機車 ➔ 轉搭台鐵「沙崙線」前往高鐵台南站**

## 🚄 台南火車站 ⇄ 台南高鐵站 轉乘提醒

* 台南高鐵站位於歸仁區，與**台鐵「沙崙站」**共構。
* 在台南火車站還完機車、領回行李後，直接進火車站搭乘**台鐵「沙崙線」區間車**（約每 30 分鐘一班，車程約 **22 分鐘**，可直接刷悠遊卡／一卡通／信用卡感應進站）。
* 抵達沙崙站後，走二樓連通道步行 2 分鐘即達高鐵驗票口。
